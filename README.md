# Remix Reels Terminator — Курсқа арналған лендинг сайт

Премиум деңгейдегі **Reels Terminator / Reels Продюсер** курсының ресми лендинг веб-сайты. Сайт заманауи интерактивті элементтермен, бейне галереямен, модульдер құрылымымен және кері байланыс интерфейсімен жабдықталған.

---

## 🚀 Мүмкіндіктер (Features)

- **Басты экран (Hero Section):** Автордың кәсіби фотосы, динамикалық статсы, курсқа жазылу батырмалары.
- **Оқу модульдері (Course Modules):** Тақырыптар, сабақтар тізімі және сабақтар бойынша ішкі бағдарламалар.
- **Портфолио & Кейстер (Portfolio & Cases):** Диас Тугамбаевтың және оқушылардың үздік жұмыстары мен рилстары. Слайдер және Сетка режимімен қарау мүмкіндігі.
- **Оқушылар нәтижелері (Testimonials):** Оқушылардың экрандық отзывтары мен статистикасы.
- **Тарифтер & Сұрақ-жауап (Pricing & FAQ):** Қатысу деңгейлері мен жиі қойылатын сұрақтар.
- **Толық адаптивтілік (Mobile-first):** Смартфондарға, планшеттерге және компьютерлерге арналған жылдам интерфейс.

## 🛠 Технологиялар (Tech Stack)

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Motion (Framer Motion)
- **Icons:** Lucide React

## 💻 Жергілікті іске қосу (Local Setup)

1. **Репозиторийді клондау:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   cd YOUR_REPOSITORY
   ```

2. **Тәуелділіктерді орнату (Dependencies):**
   ```bash
   npm install
   ```

3. **Жобаны девелопмент режимінде іске қосу:**
   ```bash
   npm run dev
   ```
   Сервер `http://localhost:3000` мекенжайында ашылады.

4. **Продакшн жинақтау (Build):**
   ```bash
   npm run build
   ```

## 📤 GitHub-қа пуш жасау нұсқаулығы (How to Push to GitHub)

### 1-әдіс: AI Studio интерфейсі арқылы (Ең оңай жолы)
1. Экранның жоғарғы оң жақ бұрышындағы **Export** / **Settings** (⚙️ баптаулар) мәзірін ашыңыз.
2. **Export to GitHub** батырмасын басыңыз.
3. GitHub аккаунтыңызды жалғап, репозиторий атауын таңдаңыз.

### 2-әдіс: Терминал (Git) арқылы қолдан пуш жасау
Кодты өз компьютеріңізге (немесе консоль арқылы) GitHub-қа жіберу үшін:

```bash
# 1. Инициализация (егер жасалмаған болса)
git init

# 2. Барлық файлдарды қосу
git add .

# 3. Коммит жасау
git commit -m "feat: complete Reels Terminator landing page"

# 4. Негізгі бұтақты main деп атау
git branch -M main

# 5. GitHub репозиторийіңізді қосу
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git

# 6. GitHub-қа пуш жасау
git push -u origin main
```
